# ZORKO corporate office website

Eleven static pages with a shared responsive design, accessible navigation, reduced-motion support, scroll reveals, animated counters, gallery filtering and a keyboard-accessible image dialog.

The current playful design uses the approved Blue voltage gradient (#6EB9F7 to #A38BEF) in place of the original neon yellow, while retaining the original orange, lilac, green and ink colors. The official logo is saved from https://zorko.in/wp-content/uploads/2025/05/ZORKO-LOGO.webp. Typography pairs Barlow Condensed with Space Grotesk. The homepage features an original SVG sculpture with pointer tilt, dragging, arrow-key rotation and R to reset. A mood switch cycles four coordinated palettes, starting with Blue voltage. Animated section reveals, floating sculpture parts, an oversized marquee, tactile image interactions and page wipes provide motion. Reduced-motion preferences disable automatic motion and transitions.

Design references reviewed: https://www.aesop.com/, https://dev-static.work.co/clients/aesop/, and https://www.vitra.com/. These informed spacing, photography and editorial composition; brand assets and content remain Zorko’s.

The latest direction also references https://toyfight.co/ for its playful interactive-object approach, large typography and pastel treatments. Its public HTML, stylesheet and preview image were inspected. The Zorko sculpture and code are original; no ToyFight models or proprietary fonts are reused. Browser automation timed out during this revision, so the latest responsive visual and interactive checks remain unverified. Static checks and JavaScript syntax checks passed.

## Run

`npm run build` generates the pages. `npm run check` checks local links and assets. `npm run dev` serves the site at http://127.0.0.1:4173.

The enquiry form prepares an email draft; it does not send or store enquiries. Careers links point to the official Zorko application page. No fabricated job openings are shown.
